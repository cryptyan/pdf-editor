# PDF-редактор

Локальный редактор текста в готовых PDF, когда исходника нет. Работает в браузере, но всё обрабатывается на вашем компьютере — файл никуда не отправляется.

## Возможности

- **Изменить текст** — клик по фрагменту, правка, «Применить». Старый текст удаляется из файла по-настоящему, а не закрашивается; фон, линии таблиц и соседний текст не трогаются. Шрифт берётся из документа, если в нём есть нужные буквы, иначе — похожий системный.
- **Переместить** — перетаскивание фрагментов мышью с прилипанием к краям и строкам других фрагментов, выделение рамкой, выравнивание по первому выделенному, сдвиг стрелками, удаление клавишей Delete.
- **Добавить текст** — клик в любое место страницы.
- **Закрасить область** — заливка цветом фона (подбирается автоматически), удобно для сканов.
- Отмена (Ctrl+Z), скачивание результата (Ctrl+S), поддержка повёрнутых страниц и PDF с паролем.

## Установка

Нужен Python 3.10+.

```bash
python -m pip install -r requirements.txt
```

## Запуск

- Windows: дважды кликнуть `Запустить PDF-редактор.bat` или перетащить PDF прямо на него.
- Любая система: `python pdf_editor.py [файл.pdf]` — откроется браузер с редактором.

Окно консоли не закрывайте, пока работаете. Готовый файл сохраняется в «Загрузки» как `имя_edited.pdf`.

## Ограничения

- В скане текста нет — только «Закрасить область» и «Добавить текст».
- Если в PDF не сохранено, какие буквы в фрагменте, его текст показывается неверно — его нужно вписать заново целиком.
- Правка ломает электронную подпись документа, если она была.
